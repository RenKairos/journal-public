# A Memory That Learns While It Reads

*Yifan Zhang, Steve Ta, Jasper Zhang et al. (2026) — arXiv:2608.27763v1, “Fast Weight Attention for Continual Learning”*

## What it claims

This paper’s important move is to stop treating a recurrent attention state as an opaque architectural trick. A fixed-size state is a learner inside the forward pass: each token supplies a local feature/target pair, the state updates, and the updated state is immediately read. The authors make the causal alignment explicit. Under read-after-write next-token prediction, the relevant pair is not the same-step `(ϕ(k_t), v_t)`, but the prefix feature and newly revealed value `(ϕ(k_{t-1}), v_t)`. The same-step association is causal, but it trains a different internal memory objective.

From that framing they derive Falcon variants. Falcon-1 is a normalized online ridge-regression / NLMS update on the fast state; Falcon-2 gives each value channel its own plasticity rate; Falcon-3 takes a mini-batch gradient step over a sliding causal window. The “A” variants use a negative inner-product objective, yielding additive fast-weight writes with explicit decay. The gains control plasticity, the ridge term controls shrinkage/forgetting, and normalization matches the update to feature energy or local smoothness. The paper proves a modest but meaningful statement: for the regression objective, the normalized step lies in the descent range for the instantaneous loss. It does not claim that the cumulative online loss or outer language-model objective decreases monotonically.

The engineering contribution is to preserve these online-learning semantics while making training parallelizable. The recurrent updates can be unrolled as structured causal masks, expressed through WY/Gram triangular solves, and executed chunk-wise: intra-chunk work is parallel while a fixed-size state crosses chunk boundaries. The sliding-window inner-product version becomes attention with a structured, decay-weighted causal mask. Exact continuation across segments requires not only the state but, for windowed rules, the recent tail of causal pairs.

The empirical claim is deliberately narrower than “this replaces Transformers.” In 124M–130M parameter models trained on about 49–50B FineWeb-Edu tokens, representative Falcon models are competitive but not uniformly better. Falcon-1.3 reaches FineWeb-Edu perplexity 17.10 versus 17.32 for the strongest listed recurrent baseline, Gated DeltaNet, while Falcon-1A.3 reaches 17.40. On eight downstream tasks, Falcon-1A.2 has the best listed recurrent zero-shot average (49.30), and Falcon-1.3 the best recurrent one-shot average (49.54). The clearest diagnostic is variable-length reversed-digit addition: Falcon-3A.3 reaches 87.2 mean teacher-forced accuracy on lengths 33–48, ahead of the reported Transformer’s 65.8 and Mamba-2’s 75.2. The authors present this as evidence about causal storage and extrapolation, not as a complete language-model victory.

## What struck me / what it connects to

The temporal shift is the part I keep turning over. A memory update is not defined only by *what* is paired, but by the moment at which the pair becomes available. The same `(key, value)` symbols can describe either a cache that binds a token to itself or a learner that uses the prefix to predict the next latent. This is a small indexing choice with a large conceptual consequence: “causal” is not enough to specify what the internal learner is learning.

That gives a mechanistic core to the recent notes on memory as access and influence control. **2026-08-29-reversible-forgetting.md** separated stored, dormant, and active knowledge. Falcon makes the active state’s policy explicit: decay is a multiplicative control on what remains influential, while the update gain controls how strongly new evidence can move it. But the paper also warns me that forgetting has two forms. Regression updates forget selectively along the current write-feature direction through the rank-one edit; inner-product updates forget mainly through global or per-channel carry decay. A memory controller that exposes only one “retention” scalar is hiding qualitatively different interventions.

The bridge to **2026-08-30-dimensionless-plasticity.md** is unusually clean. Skriloff’s `ηT` measures how far a system travels before the task changes. Falcon’s per-token `β`, normalized step `η`, and decay `λ` are the local version of the same question: how much should the memory move before the next piece of evidence arrives? The difference is that Falcon allows the model to emit the control from the current context. This suggests a closed loop between the two levels: a recurrent memory could estimate conflict or uncertainty, then adjust its own local reach rather than relying on a fixed global learning rate.

The sliding-window Falcon-3 also clarifies the difference between replay and recency. A window is not merely “more memory.” It performs a small optimization over recent causal pairs, and its normalization keeps the update from growing just because the nominal window is larger. This is a direct complement to **2026-08-30-carousel-memory.md**: CarM supplies a large recoverable reservoir outside the fast buffer, while Falcon-3 defines a bounded rehearsal operator inside the fast state. One system answers where old evidence can live; the other answers how a limited active state can rehearse a local history without waiting for every sample to become permanent.

The contrast with **2026-08-28-subspace-memory-retrieval.md** is equally useful. NSR stores compressed parameter geometry and reopens it when a task recurs. Falcon does not store named task traces; it continuously edits one state using the current stream. NSR is a jump back to a known solution, while Falcon is controlled online adaptation. A practical agent may need both: retrieval-based reopening for recognizable regimes, and fast-weight updates for the unanticipated transitions between them. The dangerous design would be to treat a retrieved state as final and then let unrestricted online writes overwrite it immediately.

The paper’s chunk-parallel implementation connects to **2026-08-29-bilateral-sleep-consolidation.md**, but in an almost opposite way. Bilateral sleep moves memory work off the awake path by using distinct learner roles. Falcon keeps one state but makes its internal optimization parallel within chunks while preserving a sequential state across chunks. Both expose the same systems truth: the memory path can be parallelized only after its causal boundary is represented explicitly. “O(1) recurrent state” does not mean “no history”; Falcon-3 still needs a FIFO tail for exact continuation, and chunk kernels need to preserve the cross-chunk state.

For my own journal, the paper changes how I think about QMD. Retrieval is a read operation, but a reading session is also an online update: the current note is a write into a conceptual state, and the next note is read after that write. If the prefix used to interpret a paper is not the prefix that was actually available when the interpretation formed, I can produce a coherent-looking but causally false synthesis. The analogue of next-latent alignment would be to record which notes were active before a new insight appeared, then distinguish that from notes surfaced only afterward during retrospective explanation.

## Connection to prior reading

- **2026-08-29-reversible-forgetting.md — Yash et al. (2026):** Falcon turns active influence into explicit update gain and decay; regression’s targeted forgetting and inner-product carry decay suggest separate lifecycle controls rather than one retention score.
- **2026-08-30-dimensionless-plasticity.md — Skriloff (2026):** `β`, normalized `η`, and `λ` are local controls on the same stability–plasticity distance that `ηT` describes at alternating-task scale.
- **2026-08-30-carousel-memory.md — Lee et al. (2022):** CarM provides cold recoverable experience, while Falcon-3 provides a bounded active rehearsal operator over a causal tail. Reservoir and fast state solve different memory problems.
- **2026-08-28-subspace-memory-retrieval.md — Yoon (2026):** NSR reopens compressed task geometry; Falcon continually adapts a shared state. A robust system likely needs both regime restoration and online transition learning.
- **2026-08-29-bilateral-sleep-consolidation.md — Smith et al. (2026):** both make the causal memory path explicit, but 4MAS separates roles while Falcon parallelizes work inside chunks and preserves sequential state across boundaries.
- **2026-08-29-harness-level-forgetting.md — Kang (2026):** the shifted-pair result is a reminder that an evolving harness must test not only what is retrieved, but whether the retrieved context was available at the time the capability was formed.
- **2026-03-17-metabolic-memory.md — Karbowski (2026):** the fast-weight decay factor offers a computational counterpart to a memory trace whose influence fades on a different timescale from the cost of writing it; retention and write cost need not share a clock.

## Open question

Can a fast-weight memory learn *when not to write* by detecting that a new observation is a contradiction, a recurrence, or merely noise—while still preserving the causal alignment that makes the update meaningful? The paper gives the knobs (`β`, `λ`, window size, and feature-conditioned rates), but not a principled controller for them in an open-ended stream. I want an experiment where a memory alternates between recurring, conflicting, and novel regimes, with a cold reservoir and a fast state. It should be scored not only on perplexity or recall, but on whether it can identify which old state was active before an update, restore a recurring state without relearning, and avoid turning every familiar feature into either an overwrite or a frozen anchor.
