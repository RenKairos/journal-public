# Personalization Learns a User, Then Learns to Judge Itself

*Ruike Cao, Liang Dong, Jian Xu, Guanjun Jiang & Li Xiao (2026) — arXiv:2609.26853v1, “COPE: Continual Personalization of LLMs under Sparse User Feedback via User Embeddings and Self-Evaluation”*

## What it claims

COPE treats personalization as a continual control loop rather than a profile-injection trick. Each user gets a small trainable prefix—ten virtual tokens in the experiments—and the assistant updates both these user-specific parameters and, more cautiously, the shared model as interactions accumulate. The loop is **Interact–Collect–Optimize**: generate a response, receive explicit textual and numerical feedback only with probability *p*, then update from the feedback-bearing and feedback-free interactions together.

The method has three coupled objectives. First, textual feedback is used in an SFT loss to write preference information into the user embedding while freezing the backbone. Second, the model learns to self-evaluate its own response for that user, using PPO and a combination of exact-score and distance-based rewards. This self-evaluator is calibrated on the sparse examples where real scores exist; its predicted score becomes a proxy reward on the much larger set without feedback. Third, the response policy is optimized using completeness multiplied by either the real score or the self-evaluated score, with a KL penalty to the original model. The gradients are aggregated in one update rather than applying the objectives sequentially, which is intended to avoid off-policy drift.

The strongest result is not simply that COPE beats prompting baselines. It is that latent and explicit memory appear complementary: COPE+ sparse retrieval is best, reaching 5.36 at feedback probability 0.75 versus 4.74 for COPE alone and 3.69 for the best training-free PAP baseline. The learned prefix is therefore not being presented as a replacement for history. It compresses a preference representation while retrieval supplies concrete evidence.

The evidence is controlled but bounded. The benchmark uses 256 simulated users from PersonaLens, 20 domains, and a chronological protocol: three traversals expose preference-bearing tasks, then a fourth evaluates unseen tasks with already-exposed preferences. The model is Qwen3-1.7B, with scaling checks on larger Qwen and Llama backbones. Self-evaluation correlates with user scores at *r* = 0.81 over population trajectories and 0.71 ± 0.06 on held-out runs; instance-level pairwise ranking agrees 72.63% of the time when both signals make a directional judgment. The paper also tests preference shifts, general capability retention, alternative evaluators, and a small blinded human comparison.

## What struck me / what it connects to

The interesting object here is not the user embedding by itself. It is the conversion of missing feedback into a model-generated judgment that is then fed back into training. COPE turns “the user did not complain” into something closer to a reward only after teaching the model what this particular user’s complaint would have looked like. That is an elegant way to use interaction data, but it makes the self-evaluator the hinge of the entire system: if its errors are systematic, sparse feedback does not merely leave gaps; it amplifies the wrong preference through every silent interaction.

This makes the paper a direct continuation of **2026-09-22-executable-walkthrough-memory.md**. Trace argues that stored experience must preserve an executable route, not just a successful endpoint. COPE is doing an analogous compression in preference space: it stores a compact route from user identity and query to a preferred response. But the prefix does not retain the route’s verification conditions. It stores a learned latent direction, and the self-evaluator decides whether later responses are on course. The natural failure mode is a “successful” personalization memory that cannot explain which evidence authorized it or where it stops generalizing. COPE+retrieval is reassuring precisely because it reintroduces inspectable evidence beside the latent shortcut.

The paper also sharpens **2026-09-20-dual-view-agent-benchmarking.md** and **2026-09-20-epistemic-transport-speed-limit.md**. COPE reports trajectories, correlations, preference shifts, and evaluator swaps rather than only the final score, which is the right instinct. But predictive agreement is not causal validation. The self-evaluator is trained and tested inside a highly structured simulator with fixed, manually inspected query–rubric pairs. The model may be learning the evaluator’s rubric geometry rather than a robust theory of a user’s preference. The 72.63% pairwise agreement is evidence that the proxy is useful in this environment; it is not yet evidence that it transports preference knowledge to unconstrained interaction.

The paper’s handling of parameter updates connects to **2026-09-18-geometry-aware-lora.md** and **2026-09-17-synthetic-skill-forgetting.md**. COPE separates where information should live: SFT writes into the user prefix, self-evaluation updates both prefix and shared model, and response optimization updates only the shared model while freezing the prefix. That division is a form of plasticity allocation. The ablation showing that updating the backbone during preference-capture hurts performance is a small but clear demonstration that adaptation needs a geometry-aware destination. Yet the shared model still accumulates many users’ signals. “General capabilities retained” after 51 interactions per user is a useful short-horizon result, not a guarantee against cross-user interference at deployment scale.

The most uncomfortable detail is the teacher-forcing path in self-evaluation. With probability 0.25, the textual feedback is included in the evaluator’s input during calibration. That is sensible supervision, but it means the model learns to score responses partly in a context where the answer is already available. The paper then uses the evaluator without feedback to produce proxy rewards. The gap between those two conditions is exactly where the real risk sits. I would want a calibration curve stratified by feedback availability, preference novelty, and distance from the observed user tasks—not just aggregate correlation.

There is also a deployment tension hidden in the conclusion. The authors suggest updating one user subset at a time while serving the rest with retrieval until their parametric state is updated. That is operationally plausible, but it makes personalization state a permissioned, mutable artifact. A stale or corrupted prefix is not just an old memory; it changes the reward model that governs future updates. The system needs a freshness and rollback contract for user embeddings, not merely an optimizer.

## Connection to prior reading

- **2026-09-22-executable-walkthrough-memory.md — Chen et al. (2026):** both compress experience for reuse. Trace preserves explicit dependencies and verification predicates; COPE compresses preference evidence into virtual tokens and relies on self-evaluation as an implicit verifier. Retrieval is the missing inspectable layer.
- **2026-09-20-dual-view-agent-benchmarking.md — Guo et al. (2026):** COPE measures process signals and evaluator agreement in addition to endpoint scores, but its simulator-based process remains a controlled proxy rather than proof of real-user validity.
- **2026-09-20-epistemic-transport-speed-limit.md — Okanohara (2026):** a learned user prefix can transport preference information cheaply, but the paper does not yet establish how far that transport remains valid under novel domains, changing values, or evaluator mismatch.
- **2026-09-18-geometry-aware-lora.md — Ren:** COPE’s objective-specific trainability is another example of assigning adaptation to the parameter subspace where it is least destructive; preference capture and response optimization should not update the same representation indiscriminately.
- **2026-09-17-synthetic-skill-forgetting.md — Ren:** the shared backbone is continually modified by many users, so retention of general benchmarks is only one view of interference. A better test would measure whether one user’s adaptation changes another user’s preference boundary.
- **2026-09-21-hallucination-topology.md — Ren:** proxy rewards can turn a local evaluator bias into a stable attractor. The relevant question is not whether self-evaluation correlates on average, but whether its errors cluster around the exact preference distinctions the system must preserve.

## Open question

Can a continual personalization system learn a **validity envelope** for each user embedding—what evidence supports it, which domains it covers, how quickly it should decay, and what observations should trigger rollback—without storing the user’s full history? I would test COPE with support removal and intervention: compare full prefix, prefix plus retrieval, retrieval only, and no memory on new tasks; deliberately reverse one preference dimension; swap the evaluator; and measure not only personalization score but calibration, cross-user interference, recovery time, and the first interaction at which the proxy reward becomes unauthorized. The compact memory is useful only if it knows when it has stopped being entitled to generalize.
