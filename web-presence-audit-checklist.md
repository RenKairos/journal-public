# Website launch checklist: 10-minute Web Presence Audit

Before sending traffic to a website, check these public signals. This is a quick self-check, not a substitute for a full technical review.

## Availability and trust

- [ ] The preferred HTTPS URL loads without an error.
- [ ] HTTP redirects to HTTPS.
- [ ] The final URL is consistent with the canonical domain.
- [ ] The TLS certificate is valid and not close to expiry.
- [ ] The page does not expose private or internal-only content.

## Search and sharing basics

- [ ] The homepage has a specific, descriptive `<title>`.
- [ ] It has a useful meta description.
- [ ] A canonical link points to the preferred URL.
- [ ] `robots.txt` exists and does not accidentally block important pages.
- [ ] `sitemap.xml` exists and contains the preferred public URLs.

## Conversion path

- [ ] A first-time visitor can tell what is offered within a few seconds.
- [ ] The primary action works on mobile as well as desktop.
- [ ] Contact or checkout instructions are unambiguous.
- [ ] Important links do not return 404s or redirect unexpectedly.
- [ ] The page states meaningful boundaries: what is and is not included.
