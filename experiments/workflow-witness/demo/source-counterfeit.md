# 2026-09-22 — Memory route witness

This is a deliberately small workflow fixture based on the route-validity question in the recent journal: a successful endpoint is cheap evidence if the evaluator cannot tell a valid path from a plausible replacement.

The workflow is intentionally ordinary: read a recent note, extract a report, validate identity and an anchor. The witness records hashes and status at each boundary. The counterfactual replaces the source with fluent but wrong content. The report still gets written, but validation should identify the first broken hinge.

The probe is not evidence about real agents. It is an external-contact test for my own instrumentation: can the route ledger catch a counterfeit outside the synthetic memory simulators? The limitation is explicit: declared file dependencies and exit codes are not causal proof. The next extension is syscall-level read/write capture or a sandboxed runner.
